## 📖 Overview

**North Gate** is a fully responsive multi-page corporate website for an industrial services group. It presents six core business domains through a clean, professional interface:

- ⚡ **Energy Solutions** — Solar panel installation, inverters & renewable energy services
- 🚢 **Export & Import** — Global trade, customs clearance & freight forwarding
- 🏗️ **General Contracting** — Residential, commercial & industrial construction
- 📦 **General Trading** — Global product sourcing & trade solutions
- 🚚 **Logistics** — Transport, warehousing & supply chain management
- 🛢️ **Oil & Gas Services** — Exploration, production & environmental solutions

The site uses a lightweight **single-page-application (SPA) router** so the header and footer stay persistent while each service page loads seamlessly — no page reloads.

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| 🧭 **SPA Navigation** | Hash-based router (`#/energy-solutions`, etc.) loads pages instantly without reloading the header/footer |
| 🏠 **Dynamic Home Page** | Hero banner with animated background, stats bar, service cards grid & CTA section |
| 🎠 **Service Pages** | Six fully-designed pages rendered in an isolated frame — each keeps its own styles & animations |
| 📱 **Fully Responsive** | Mobile-first layout with hamburger navigation & dropdown menus |
| 🍞 **Breadcrumb Bar** | Structured `Home / Service` breadcrumb above each service page |
| 📬 **Contact Page** | Working contact form with success state + contact details |
| 🔍 **SEO-Friendly** | Semantic HTML, meta descriptions & per-page titles |
| ⚡ **No Dependencies** | Pure HTML, CSS & vanilla JavaScript — no build tools required |

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, Safari)
- *(Optional)* [Git](https://git-scm.com/) for version control

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/muzzamil7770/north-gate-services.git
   ```

2. **Navigate to the project folder**

   ```bash
   cd north-gate-services
   ```

3. **Open the website**

   Simply open `index.html` in your browser — no build tools or server required. 🎉

   ```bash
   start index.html        # Windows
   open index.html         # macOS
   ```
